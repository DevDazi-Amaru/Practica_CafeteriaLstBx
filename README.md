# Practica_CafeteriaLstBx
**Hola! Este es el primer repositorio subiendo una practica realizada en mi Universidad**

Para esta ocasión,cree un sistema simlpe para una cafeteria la cual es capaz de:

Mostrar un **Listbox** predeterminado como menu
Mostrar un **combobox** con las mismas opciones del listbox
Conectar el seleccionado de el **listbox menu** con el **combobox** de opciones 
Mostrar una imagen del platillo tanto si es seleccionado con el **combobox** o con el **listbox**
Agregar la comida seleccionada al **listbox de pedido** 
Si hay un pedido seleccionado se puede eliminar ese producto
Si no hay un pedido seleccionado y hay pedidos en el **listbox** elimina el ultimo pedido en la lista
Puede limpiar todos los pedidos en el **listbox de pedidos**
Y al finalizar la compra este factura en un pequeño **message box **

**Posee la mayoria de validaciones posibles, si me hizo falta alguna por favor comentala**

# Contexto
Mas que cafeteria mi programa esta basado en un restaurante ficticio

El restaurante ficticio tiene como nombre **"Hambre eh Loquemah Tengoh"** y su mercadería esta centrada en comida India (a como quise expresar en su nombre)

En teoria el restaurante **"Hambre eh Loquemah Tengoh"** No contaba con alguna herramienta que facilitara a los mozos o meseros a facturar facilmente un pedido.

Este pequeño programa llega para anotar el pedido que realizo el cliente y mostrar la factura de su compra final
